# 338. Counting Bits - LeetCode

## Problem Statement / Goal
Given an integer `n`, return an array of length `n + 1` such that for each `i` ($0 \le i \le n$), the element at that index is the number of `1`s in the binary representation of `i`.

## Approach & Logic
1. Allocate an array of size `n + 1` to store the count of set bits for each integer from `0` to `n`.
2. For each number `i` from `0` to `n`:
   - Initialize a temporary variable `temp = i` and a counter `count = 0`.
   - Repeatedly check the last bit using `temp % 2` (or bitwise AND with 1) and increment `count` if it is 1.
   - Shift or divide the temporary variable by 2 (`temp /= 2`).
   - Store the computed count at `result[i]`.
3. Set the `returnSize` output parameter to `n + 1`.
4. Return the populated array.

## Detailed Code Walkthrough
- `int* countBits(int n, int* returnSize)`: The main function interface matching the LeetCode signature.
- `*returnSize = n + 1;`: Sets the returned array size.
- `int *result = malloc((n + 1) * sizeof(int));`: Dynamically allocates memory for the result array.
- `for (int i = 0; i <= n; i++)`: Iterates from 0 up to `n`.
- `int temp = i; int count = 0;`: Creates local state to compute the binary representation of `i`.
- `while (temp > 0)`: Repeatedly divides by 2 to extract binary digits.
  - `count += temp % 2;`: Adds 1 if the remainder is 1 (meaning the least significant bit is set).
  - `temp /= 2;`: Integer division by 2 shifts the bits of `temp` right by one position.
- `result[i] = count;`: Saves the final count.
- `return result;`: Returns the dynamically allocated integer array.

## Complexity Analysis
- **Time Complexity:** $O(n \log n)$. For each number `i`, we divide it by 2 repeatedly, taking $O(\log i)$ operations. Total operations: $\sum_{i=0}^n \log i \approx O(n \log n)$.
- **Space Complexity:** $O(1)$ auxiliary space (excluding the output array of size $n + 1$).
