# 476. Number Complement - LeetCode

## Problem Statement / Goal
The complement of an integer is the integer you get when you flip all the `0`s to `1`s and all the `1`s to `0`s in its binary representation. Given an integer `num`, return its complement.

## Approach & Logic
1. Convert the integer `num` to its binary string representation.
2. Invert every character of the binary string (`'0'` becomes `'1'`, and `'1'` becomes `'0'`).
3. Convert the inverted binary string back to an integer.
4. Return the calculated integer.

## Detailed Code Walkthrough
- `void reverse(char* bin)`: Utility function that reverses a string in-place.
- `void ToBinaryString(int num, char* bin_str)`:
  - Converts an integer into its binary string representation.
  - Computes bits in reverse (using modulo and division by 2) and stores them in `bin_str`.
  - Calls `reverse` to get the correct MSB-to-LSB order.
- `int ToNumFromString(char* bin_str)`:
  - Parses a binary string and converts it back into a base-10 integer.
  - Uses `res = res * 2 + bit` iteration.
- `int findComplement(int num)`:
  - Calls `ToBinaryString` to get the binary representation of `num`.
  - Loops through each character and flips `'0'` to `'1'` and vice versa.
  - Appends a null-terminator to the complement string.
  - Calls `ToNumFromString` on the complemented binary string and returns the resulting decimal integer.

## Complexity Analysis
- **Time Complexity:** $O(\log (\text{num}))$ because the number of binary bits in `num` is proportional to $\log_2(\text{num})$. We loop through these bits a constant number of times (reversal, flipping, and reconstructing the number).
- **Space Complexity:** $O(\log (\text{num}))$ to store the temporary string representation of the binary digits (at most 64 bytes).
