# 693. Binary Number with Alternating Bits - LeetCode

## Problem Statement / Goal
Given a positive integer `n`, check whether it has alternating bits. That is, whether two adjacent bits will always have different values (e.g., `101010` is alternating, but `1101` is not).

## Approach & Logic
1. Convert the integer `n` into its binary representation as a string.
2. Iterate through the binary string starting from index 1.
3. Compare each bit at index `i` with its predecessor at index `i - 1`.
4. If they are equal, return `false`.
5. If the loop completes without finding any adjacent matching bits, return `true`.

## Detailed Code Walkthrough
- `bool hasAlternatingBits(int n)`: Checks if the input integer has alternating bits.
- `string binary = ""; while(n>0) { ... }`:
  - Continually divides `n` by 2 and prepends the remainder `(n % 2)` as a character to the `binary` string.
  - Divides `n` by 2 to process the next bit.
- `bool res = true;`: Sets the default response to true.
- `for(int i = 1; i < binary.length(); i++)`: Loops through the binary characters.
- `if(binary[i] == binary[i-1]) { return false; }`: Returns false if any duplicate adjacent character is detected.
- Returns `res` (which will be `true` if all adjacent bits are alternating).

## Complexity Analysis
- **Time Complexity:** $O(\log N)$ where $N$ is the input number. The number of bits is proportional to $\log_2 N$, and both string creation and traversal take $O(\log N)$ time.
- **Space Complexity:** $O(\log N)$ to store the binary string.
