# 67. Add Binary - LeetCode

## Problem Statement / Goal
Given two binary strings `a` and `b`, return their sum as a binary string.

## Approach & Logic
1. Use a pointer for each string starting at the last index (least significant bit) and moving towards the beginning (most significant bit).
2. Keep track of a `carry` variable (initially 0).
3. In each iteration, compute the sum of the current bits of `a` and `b` (if within bounds) plus the `carry`.
4. Append the bit `sum % 2` to the front of the result string.
5. Update `carry = sum / 2`.
6. Repeat until both string pointers are exhausted and there is no remaining `carry`.

## Detailed Code Walkthrough
- `string addBinary(string a, string b)`: Main method that accepts two binary strings and returns their sum.
- `int len1 = a.size() - 1; int len2 = b.size() - 1;`: Sets pointers to the end of the strings.
- `int carry = 0; string res = "";`: Initializes carry and result accumulator.
- `while (len1 >= 0 || len2 >= 0 || carry)`: The loop runs as long as there is a bit to process from `a` or `b`, or if there is a leftover carry.
- Inside the loop:
  - `int sum = carry;`: Sum starts with the carry from the previous position.
  - `if (len1 >= 0) { sum += a[len1--] - '0'; }`: Adds bit from `a` if still within range, then decrements pointer.
  - `if (len2 >= 0) { sum += b[len2--] - '0'; }`: Adds bit from `b` if still within range, then decrements pointer.
  - `res = char(sum % 2 + '0') + res;`: Prepends the resulting sum bit to the front of string `res`.
  - `carry = sum / 2;`: Recomputes carry for the next position.
- Returns `res`.

## Complexity Analysis
- **Time Complexity:** $O(\max(N, M))$ where $N$ and $M$ are the lengths of strings `a` and `b`. We traverse both strings at most once.
- **Space Complexity:** $O(\max(N, M))$ to store the resulting output string.
